# 成员 B：HTTP 配对性能报告

2026-10-27：已实现同一 Rust release 实验入口的配对采样、原始数据导出、统计重算与证据校验，方法和复现命令见 [bench/README.md](../bench/README.md)。

本机 Windows 应用程序控制策略阻止 Rust 新构建脚本执行（OS 4551），因此不把本机冒烟或跳过的真实进程测试当作正式性能结果。正式验证使用 Ubuntu CI 构建共享例程，先执行真实回归，再采集 3 轮 × 2 模式 × 3 场景 × 100 次的数据。当前文档暂不填写尚未实际测得的延迟数字，结果核验后更新。

正式结果应同时满足：1800 个正式样本与 360 个独立预热样本、6 个独立实例、同一 release 二进制和相同配对输入、动态正确消费而基线不消费、实际文件与 API/磁盘审计一致、CSV 与脱敏响应可重算一致。任一失败整次运行不合格。

本项不包含权限窗口和峰值 RSS；两者不得由本项延迟样本推算。
