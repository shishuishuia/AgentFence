# 安全边界与运行约束

AgentFence Lite 是经过 HTTP 网关的文件工具权限执行者。Agent 只有任务绑定 Token；管理员持有单独的环境凭证，控制阶段与租约。浏览器只能通过成员 B 的只读代理查询状态，路由守卫不承担权限执行。

## 已执行的限制

- 未识别身份、工具、阶段、路径和租约默认拒绝。普通 Agent 不能访问任何管理路由。
- 配置在启动时固定工作区，客户端不能注册任意根目录。阶段只顺序前进，done 不可恢复。
- 相对路径逐项匹配明确允许列表，检查每级符号链接/重解析点和规范路径的组成部分。目录、设备、路径穿越、字符串前缀扩展不被授权。
- 每个任务对控制面变更和工具执行串行化；同一注册工作区的工具操作也串行化。写入只覆盖已有普通文件，采用同目录临时文件完成写入及同步后替换，再消费一次租约。
- TTL 使用进程单调时钟，等于截止点即过期；UTC 仅供审计展示。已进入执行区并通过检查的写入可以完成，不会在 TTL 到期或请求断连时强行取消。
- 允许调用前记录 pending intent，执行后记录 result。审计失败永久关闭本实例的工具执行；健康检查变为 503。管理变更先记录事件再提交内存状态。
- 目标文件已替换而 result 写入失败时，响应保留 allowed=true、executed=true 及已消费次数，并返回 AUDIT_UNAVAILABLE；客户端不得自动重试。
- 审计位置不能位于任何受控工作区内。JSONL 写入串行且每行同步；普通日志、查询和审计不保存凭证或文件内容。

## 必须成立的环境前提

工作区为管理员建立的受信任静态夹具。不存在恶意并发修改、外部引入的硬链接、特殊 ACL/扩展属性或高权限进程攻击。根目录启动时规范化；注册根目录不应重复或重叠。不同任务引用同一工作区会共享内容，后一次替换可覆盖前一次，不具有任务间内容隔离。

路径检查之后再打开文件存在 TOCTOU 窗口。本期没有实现 openat2 等无竞态打开机制，也没有 OS 级文件或网络隔离。测试证明所列路径输入与静态符号链接被拒绝，不能据此证明抵御恶意并发替换。Agent 绕过 Broker 直接使用宿主机 API 时，这些限制不生效。

临时文件替换保留普通权限位；Unix 用例验证了 mode 保留。不承诺复制所有权、所有 ACL、扩展属性、文件标识或跨文件事务。目录未进行断电事务同步，不保证断电/进程崩溃时文件、内存租约和审计的一致恢复。

## 恢复与资源范围

任务、Agent Token、租约和在线事件均保存在内存。审计故障修复后必须重启，所有旧身份/授权失效。结果不完整的 intent 只能说明执行结果尚未确认，管理员应检查真实文件，不以缺失 result 推断“没有写入”。

日志没有防篡改签名，不能宣称生产级取证能力。演示仅监听回环地址，不提供 TLS、用户登录、多租户、限流、持久任务库或长期事件淘汰。当前实例事件会一直保留，内存与 JSONL 可随演示增长；不应对公网或不受信任的长期负载开放。

本期自行编写的 Rust 使用 workspace `unsafe_code = "forbid"`。依赖内部仍可能使用 unsafe；完整依赖及声明许可证见 provenance.md 和 dependency-licenses.json。
